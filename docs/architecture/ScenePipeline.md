# Scene Pipeline Documentation

This document describes the `ScenePlan` and `SceneDefinition` objects, which are central to the Scene Pipeline.

## 1. ScenePlan

The `ScenePlan` is a high-level description of the scene's overall structure and mood. It is generated by the `ScenePlanner` based on the blueprint. It does not contain specific assets, but rather the intent for the scene.

### Schema

```json
{
  "camera": {
    "type": "PerspectiveCamera" | "OrthographicCamera",
    "position": [x, y, z],
    "fov": 75,
    "near": 0.1,
    "far": 1000
  },
  "lights": [
    {
      "type": "AmbientLight" | "DirectionalLight" | "PointLight",
      "intensity": 1.0,
      "color": "#FFFFFF",
      "position": [x, y, z]
    }
  ],
  "environment": {
    "background": "sky" | "color" | "transparent",
    "fog": {
      "type": "linear" | "exponential",
      "color": "#000000",
      "near": 1,
      "far": 100
    }
  },
  "hdri": {
    "assetId": "string",
    "intensity": 1.0
  },
  "materials": {
    "default": { "type": "MeshStandardMaterial", "color": "#FFFFFF" },
    "overrideId": { "...material properties" }
  },
  "postProcessing": [
    {
      "type": "Bloom" | "DepthOfField" | "Vignette",
      "...effect properties"
    }
  ],
  "animations": [
    {
      "target": "nodeId",
      "animation": "string",
      "loop": true
    }
  ],
  "interaction": [
    {
      "target": "nodeId",
      "event": "onClick",
      "action": "navigate",
      "payload": "/path"
    }
  ],
  "performance": {
    "profile": "balanced" | "low" | "high",
    "lodStrategy": "distance" | "performance",
    "mobileFallback": "string"
  }
}
```

## 2. SceneDefinition

The `SceneDefinition` is the final, detailed output of the asset intelligence pipeline. It is a concrete, render-ready description of the entire scene, including the scene graph and references to all resolved assets. It is generated by the `SceneComposer`.

### Schema

```json
{
  "version": "1.0",
  "scene": {
    // Inherits all properties from the ScenePlan
    "camera": { ... },
    "lights": [ ... ],
    "environment": { ... },
    // ... etc. ...
    "nodes": [
      {
        "id": "string",
        "type": "Group" | "GLTF" | "Text" | "Image",
        "position": [x, y, z],
        "rotation": [x, y, z],
        "scale": [x, y, z],
        "assetId": "string", // If node is linked to an asset
        "children": [
          // other nodes
        ]
      }
    ]
  },
  "assets": {
    // The AssetManifest
    "assetId1": {
      "type": "model",
      "format": "gltf",
      "uri": "https://.../model.gltf",
      // ... other asset properties
    }
  }
}
```
